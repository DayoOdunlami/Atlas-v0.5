# ATLAS Research Pack — Notion Setup

Create a Notion workspace (or section) called **ATLAS v5 Research** with these pages.
Paste each numbered file below into its own Notion page. Share pages with "Anyone with link can view"
(or export as PDF) for ChatGPT / Claude / Gemini research sessions.

## Page map

| Notion page title | Source file | Purpose |
|-------------------|-------------|---------|
| ATLAS — Product Brief & Outcomes | `01-PRODUCT-BRIEF.md` | What we're building, waterfall, surfaces |
| ATLAS — Architecture & Stack | `02-ARCHITECTURE.md` | Current tech, dual transport, data model |
| ATLAS — Sprint Status (Jun 2026) | `03-SPRINT-STATUS.md` | What's shipped vs open |
| ATLAS — Open Gaps & Backlog | `04-OPEN-GAPS.md` | What research should prioritise |
| ATLAS — Benchmark Queries & Eval | `05-BENCHMARK-EVAL.md` | Canonical queries + scoring |
| ATLAS — Research Seeds | `06-RESEARCH-SEEDS.md` | Starter repos, categories, constraints |

## After creating pages

1. Copy each page's public URL into `07-EXTERNAL-AI-PROMPT.md` (URL placeholders).
2. Paste `07-EXTERNAL-AI-PROMPT.md` into ChatGPT (attach PDFs or paste page contents if no Notion connector).
3. Optional: add screenshots to a 7th Notion page "ATLAS — UI Screenshots" and link it in the prompt.

## Updating

When sprints ship, update pages 03 and 04 only. Re-run research with the same prompt.
