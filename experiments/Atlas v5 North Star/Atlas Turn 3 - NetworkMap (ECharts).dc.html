The call

For a 3–4 node ego-network, hand-SVG is genuinely the honest, controllable choice — the library earns its weight only once nodes scale up or you want provenance-on-hover and zoom as live affordances. Force-directed (graph-force / D3 force) stays off the table either way — it manufactures the false density this whole answer exists to refuse. If we adopt ECharts, it's always layout: 'none'.
